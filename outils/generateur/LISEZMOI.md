# Générateur du contenu de données

Scripts Python qui produisent le datapack (structures NBT, biomes, dimensions, fonctions, dialogues)
et le pack de textures. `python3 build.py` écrit dans `out/`, puis le contenu est copié dans
`src/main/resources/` du mod. `valider.py` vérifie le pack contre les données officielles 26.3.
